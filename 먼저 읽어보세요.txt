캡처도구 v1.11.1
================

1. 이 폴더 전체가 한 세트입니다. 안쪽 파일만 따로 옮기면 실행되지 않습니다.
   바탕화면이나 C:\캡처도구 처럼 찾기 쉬운 곳에 폴더째 두세요.

2. "캡처도구.exe" 를 두 번 누르면 실행됩니다. (설치 과정 없음)
   창은 뜨지 않고, 작업표시줄 오른쪽 끝 시계 옆에 파란 아이콘이 생깁니다.

3. 처음 실행할 때 파란색 "Windows의 PC 보호" 창이 나오면
   [추가 정보] -> [실행] 을 누르세요. 처음 한 번만 나옵니다.

4. PrtScn (Print Screen) 키를 누르면 캡처가 시작됩니다.

자세한 사용법은 같은 폴더의 "사용설명서.html" 을 더블클릭해서 보세요.

주요 단축키
-----------
  PrtScn            영역 캡처
  Ctrl + PrtScn     전체 화면 캡처
  Alt  + PrtScn     지금 보고 있는 창 캡처
  Shift+ PrtScn     3초 뒤 캡처
  Ctrl + Alt+PrtSc  스크롤 캡처 (긴 화면 이어붙이기)
  Ctrl + Alt + W    창 골라서 캡처 (가려져 있어도)
  Ctrl+Shift+PrtSc  직전에 잡았던 영역 그대로 다시 캡처
  F4                클립보드를 핀으로 고정 (이미지·글자·색 코드)
  Ctrl + Alt + H    핀 모두 숨기기 / 보이기
  Ctrl + Alt + Z    닫은 핀 되살리기
  Ctrl + Alt + T    핀 클릭 통과 켜기 / 끄기
  Ctrl + Alt + L    최근 캡처 목록
  Ctrl + Alt + O    저장 폴더 열기

  ※ 캡처 중에 Tab 을 누르면 이 목록이 화면에 나옵니다.

영역을 고를 때
--------------
  마우스만 올리기    그 자리의 영역이 파랗게 잡힙니다. 클릭하면 캡처
  휠 굴리기          잡는 단위 바꾸기
                     위로 = 넓게 (칸 -> 내용 영역 -> 창 전체 -> 모니터)
                     아래로 = 좁게
  제목표시줄 위       창 전체가 잡힙니다
  창 안쪽으로 조금    내용 영역만 잡힙니다 (크롬이면 웹 페이지 부분)
  드래그            화면의 경계선에 착 붙습니다
  Alt (누른 채)     붙지 않게
  Shift (누른 채)   정사각형으로
  Ctrl (누른 채)    창 전체 잡기 (Ctrl+Shift 는 모니터 전체)
  방향키            마우스를 1픽셀씩 옮기기 (Shift 는 10픽셀)
  Space             마우스 없이 시작점/끝점 찍기
  C                 마우스 아래 색 코드 복사 (Shift+C 는 RGB 숫자)
  , / .             예전에 잡았던 영역 불러오기 (더 예전 / 최근)
  R                 화면 자 — 같은 색이 이어지는 가로·세로 길이
  Q                 (영역을 정한 뒤) QR 코드 읽기
  Tab               안내판을 핀·전역 단축키 안내로 넘기기
  F1                화면 단축키 안내 켜기/끄기

캡처 편집 창에서
----------------
  Space (누른 채)   손 모양으로 바뀌고, 끌면 화면이 따라 움직입니다
  마우스 가운데 버튼 Space 없이도 같은 방식으로 움직입니다
  Ctrl + 휠         마우스가 가리키는 곳을 기준으로 확대/축소
  Shift + 휠        가로로 이동
  Ctrl + Z / Y      되돌리기 / 다시 실행

  V (선택 도구) 로 그려 놓은 도형을 고르면
  ---------------------------------------
  모서리의 흰 점    끌어서 크기 조절 (Shift 는 비율 유지)
  방향키            1픽셀씩 이동 (Shift 는 10픽셀)
  위쪽 줄의 색·굵기  고른 도형에 바로 적용됩니다
  Ctrl + D          복제
  Ctrl+Shift+↑ / ↓  맨 앞으로 / 맨 뒤로
  Delete            지우기

  [이미지 ▾] 메뉴
  ---------------
  Ctrl+Shift+L / R  왼쪽 / 오른쪽으로 90도 돌리기
  좌우·위아래 뒤집기
  여백·테두리 두르기  흰 배경 캡처의 경계가 보이게
  이미지 크기 바꾸기  메일 첨부용으로 줄일 때
  날짜 도장 / 워터마크 오른쪽 아래에 날짜나 기관명

글자 추출이 안 될 때
--------------------
  트레이 아이콘 오른쪽 클릭 -> [글자 추출 진단] 을 누르세요.
  이 컴퓨터가 실제로 어떤 언어를 읽을 수 있는지 확인해서,
  필요하면 설치 명령까지 복사해 줍니다.

파일 이름에 창 제목 넣기
------------------------
  설정 -> 저장 -> 파일 이름 에서 %W 를 쓰면
  캡처한 창의 이름이 파일명에 들어갑니다.
  예) %W_%Y%m%d_%H%M%S  ->  카카오톡_20260825_143012.png

모든 설정은 트레이 아이콘 오른쪽 클릭 -> 설정 에서 바꿀 수 있습니다.


단축키가 안 먹힐 때
-------------------
  "단축키를 등록하지 못했습니다" 알림은 그 키를 다른 프로그램이
  먼저 쓰고 있다는 뜻입니다. (캡처도구 잘못이 아닙니다)

  v1.7 부터는 이럴 때 비어 있는 다른 조합을 찾아 알아서 대신 잡고,
  무엇이 어떻게 바뀌었는지 알려 줍니다.

  트레이 아이콘 오른쪽 클릭 -> [단축키 진단] 을 누르면
  어떤 키가 왜 막혔는지 하나씩 확인하고 빈 키로 바꿀 수 있습니다.

  막힌 기능도 트레이 아이콘 메뉴에서는 그대로 쓸 수 있습니다.

단위영역 캡처 (v1.8)
--------------------
  캡처를 시작하고 마우스를 창 위에 올려 보세요.

    제목표시줄 위        -> 창 전체
    창 안쪽으로 내리면   -> 내용 영역만 (탭·주소창을 뺀 부분)
    휠을 굴리면          -> 단위를 자유롭게 넓히거나 좁히기

  화면 그림을 보고 찾는 '칸' 도 그대로 쓰지만, 사진 속 흰 여백이나
  텅 빈 배경처럼 '넓기만 하고 아무것도 없는 곳' 은 이제 잡지 않습니다.

모니터가 여러 대일 때
---------------------
  모니터마다 배율(디스플레이 크기 설정)이 달라도 정상 동작합니다.
  예) 왼쪽 125% + 오른쪽 100%

  v1.8 까지는 캡처 화면을 창 하나로 두 모니터에 걸쳐 띄웠는데,
  Windows 는 창 하나에 배율을 하나만 줍니다. 그래서 배율이 다른
  모니터에서는 화면이 작게(예: 80%) 그려지고 나머지가 흰색으로 비었습니다.

  v1.9 부터는 모니터마다 캡처 화면을 따로 띄웁니다.
  각 창이 자기 모니터의 배율을 제대로 받으므로 어긋나지 않습니다.
  모니터를 가로질러 드래그하는 것도 그대로 됩니다.

  내 모니터 배율이 궁금하면:
  트레이 아이콘 오른쪽 클릭 -> [진단 정보 저장] 을 누르면
  모니터별 해상도와 배율이 파일에 적힙니다.

지금 쓰는 버전이 궁금하면
-------------------------
  작업표시줄 오른쪽 캡처도구 아이콘에 마우스를 올리면
  "캡처도구 v1.10.0" 처럼 버전이 뜹니다.
  아이콘을 오른쪽 클릭해도 메뉴 맨 위에 적혀 있습니다.

  ※ 업데이트 파일은 '누적본' 입니다.
     어느 버전에서 멈췄든, 최신 파일 하나만 덮어쓰면 됩니다.
     중간 버전을 차례로 설치할 필요가 없습니다.

자동 업데이트 (v1.11.0 부터)
----------------------------
  켜 두면 프로그램이 알아서 새 버전이 나왔는지 확인하고, 미리 받아 둡니다.

  동작 순서
    1. 프로그램을 켜고 잠시 뒤, 하루에 한 번 조용히 확인합니다.
       (캡처는 그동안에도 평소처럼 쓸 수 있습니다)
    2. 새 버전이 있으면 뒤에서 내려받아 둡니다.
    3. 다 받으면 알림이 뜨고, 트레이 메뉴 맨 위에
       "새 버전 v1.12.0 설치하기" 줄이 생깁니다.
    4. 그 줄을 누르면 변경점을 보여 주고, [지금 적용] 을 누르면
       파일을 바꾼 뒤 다시 시작할지 물어봅니다.

  안전장치
    * 설정.json, 자료 폴더, runtime 폴더는 절대 건드리지 않습니다.
      설정과 캡처한 이미지는 그대로 남습니다.
    * 바꾸기 전에 지금 파일을 자료\업데이트\백업_... 에 보관합니다.
    * 바꾸는 도중 문제가 생기면 백업에서 자동으로 되돌립니다.
    * 받은 꾸러미가 캡처도구가 맞는지, 정말 더 높은 버전인지
      확인한 뒤에만 바꿉니다.

  끄거나 바꾸려면
    설정 > 기타 탭 > 업데이트 칸에서
    자동 확인을 끄거나, 확인 주기(기본 24시간)를 바꿀 수 있습니다.
    [지금 확인] 을 누르면 즉시 확인합니다.

  따로 해 줄 일은 없습니다
    코드가 공개 저장소에 있어서 아무 설정 없이 바로 동작합니다.

    (참고) 나중에 저장소를 비공개로 바꾸면 GitHub 접근 열쇠(토큰)가
    필요해집니다. 그때는 GitHub 에서 "repo" 권한 토큰을 만들어
    자료 폴더 안 "업데이트토큰.txt" 에 한 줄로 넣으면 됩니다.
    이 파일은 저장소에 올라가지 않도록 막아 두었습니다.

v1.11.1 에서 달라진 점
